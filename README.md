# Flight Route Optimizer

## Overview

The **Flight Booking Optimizer** is a client-side web application designed to identify the most cost-efficient flight route between two cities. The project demonstrates the practical application of graph-based optimization techniques combined with a clean and responsive user interface.

This application focuses on simplicity, performance, and clarity, making it suitable as an academic project, portfolio showcase, or foundation for further enhancements.


## Key Features

- Cost-efficient flight route discovery between cities
- Graph-based route modeling and optimization
- Responsive and modern UI built with Tailwind CSS
- Lightweight, browser-based implementation  
- Modular and maintainable code structure  


## Technology Stack

- **HTML5** – Application structure  
- **CSS3 / Tailwind CSS** – Styling and responsiveness  
- **JavaScript (ES6+)** – Application logic  
- **Graph Algorithms** – Route optimization logic
